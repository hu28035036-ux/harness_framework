# PRD: 쩔로그 MVP

## 목표
쩔로그는 메이플 플래닛 기반 쩔/잠쩔 작업에서 기사와 손님이 작업 조건, 인증자료, 후기, 이전 작업물, 사기꾼 주의 정보를 한곳에서 확인하게 하는 인증/홍보 플랫폼이다.

## 사용자와 권한
- 손님: 기사 탐색, 기사구함 글 작성, 인증게시글 확인, 평점 작성, 사기꾼 제보, 오류/건의 작성.
- 기사: 손님 기능 + 기사 프로필 관리, 작업홍보게시글 작성, 기사구함 댓글 작성, PC 프로그램 작업 인증.
- 관리자: 공지/업데이트 관리, 사기꾼 제보 검토, 사기꾼 목록 관리, 오류/건의 상태 관리.

## 1차 MVP 포함
- 웹페이지: 메인페이지, 기사목록, 기사 프로필, 기사구함, 사기꾼, 오류 및 건의사항, 설정.
- 기사 홍보: 기사 프로필, 오픈카톡/디스코드 버튼, 작업홍보게시글, 이전 작업물.
- 작업 인증: PC 프로그램에서 작업 시작, 인증캡처, 30초 클립, 인증게시글 최종 게시.
- 손님 확인: 인증게시글 링크 확인, 1/2/3점 평점, 1점 사유 작성.
- 장시간 모드: 3시간 이상 작업에서 보류/이어하기, 반복 중간 클립, 자동 인증캡처.
- 업데이트/복구: 선택/강제 업데이트, 작업 중 수동저장, 미게시 작업 복구.
- 운영 정책: 현금거래 미지원, 자동사냥/매크로 금지, 사기꾼 제보/목록 관리.

## MVP 제외
- 예약 신청/수락/매칭 확정.
- 플랫폼 내 결제, 정산, 환불 중재.
- 게임 자동 조작, 자동사냥, 자동 키입력, 거짓말탐지기 자동 대응.
- 주민등록번호 직접 수집.

## 완료 기준
- 손님이 웹에서 기사 프로필, 홍보글, 기사구함 글, 인증게시글, 후기, 사기꾼 목록을 확인할 수 있다.
- 기사가 PC 프로그램에서 작업 시작, 캡처, 클립 생성, 인증게시글 최종 게시를 완료할 수 있다.
- 인증캡처에 타임스탬프, 세션 ID, 기사명, 손님 닉네임, 사냥터가 자동 합성된다.
- 작업홍보게시글 10분 제한이 웹/프로그램 양쪽에서 동일하게 적용된다.
- 장시간 모드에서 보류/이어하기/재개 클립이 정상 동작한다.
- 강제 업데이트 중 작업 자료가 수동저장/복구 가능하다.
- 사기꾼 제보/목록 기능이 개인정보 비공개 원칙으로 동작한다.

## 확정 기술 기준
- 웹페이지: Next.js.
- 배포: Vercel Pro.
- DB/Auth/Storage: Supabase Pro.
- PC 프로그램: Python + PySide6 + FFmpeg.
- 파일 저장: 1차는 Supabase Storage.
- 영상 증가 시 Cloudflare R2로 분리 가능하게 저장소 계약을 유지한다.
